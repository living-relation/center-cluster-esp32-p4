TrackCluster — CAN Live Sender

Connect to CAN adapter

Starting native bridge…
Auto-connects the moment a supported adapter is plugged in — it opens the bus but never transmits until you press Send / enable "Send continuously". Detects gs_usb/candleLight (CANable, CANtact, Innomaker), slcan COM-port adapters, Seeed USB-CAN Analyzer, and PEAK / Kvaser / Vector when their vendor driver is installed. Older candleLight firmware may still need the WinUSB driver bound via Zadig once. The adapter is shared across both device profiles — switching device does not drop the link.

Bus settings (fixed, same for every frame)

Bitrate1 Mbit/s default — selectable in the Connect panel above
ID typeStandard / 11‑bit (every ID below is < 0x800)
Frame typeData frame (not RTR)
DLC (data length)8 bytes, always
Byte orderBig‑endian — already baked into the bytes shown
