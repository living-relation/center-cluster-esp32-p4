TrackCluster Center — CAN Bench Test Tool

Fakes the Link G4X ECU: pick a gauge, type the value it should show, get the raw CAN frame to paste into CANgaroo, PCAN‑View, SavvyCAN, or any slcan/candleLight app. Built from the center cluster's actual decoder (main/canbus.c, main/protocols/link_g4x.json) — not a placeholder map.

Bus settings (same for every frame)

Bitrate1,000,000 bps (1 Mbit/s)
ID typeStandard / 11‑bit (every ID below is < 0x800)
Frame typeData frame (not RTR)
DLC (data length)8 bytes, always — pad with the zeros shown
Byte orderBig‑endian — already baked in, paste the hex left‑to‑right as shown
CANgaroo (candleLight/CANable): Connect → Bitrate 1000000 → Connect. New frame → ID (hex), Standard, DLC 8, paste data bytes.
PCAN‑View (PEAK PCAN‑USB): Connect → Baud rate "1 MBit/s". Transmit → New Message → ID hex, Standard, DLC 8, data bytes.
SavvyCAN (CANable/SLCAN and most adapters): Connection → bus speed 1000000. Send window → CAN ID hex, Extended off, 8 data bytes.

What this covers

0x3E8 (10 ms)RPM, Boost/MAP, Coolant, IAT, Oil Temp
0x3E9 (10 ms)Ignition, Speed, Oil Pressure, Fuel Pressure
0x3EA (10 ms)Lambda
0x3EB (50 ms)Gear, Fuel Level
0x3EE (50 ms)6 warning flags → right‑screen overlay
Each frame below carries several gauges together — a real ECU sends all its fields in one message, so fill in everything you care about in that card, then copy the one 8‑byte frame. Fields you leave alone use safe idle‑engine defaults, not zero.
Send 0x3E8 / 0x3E9 / 0x3EA / 0x3EB repeatedly (every 10–50 ms, matching the period shown) to keep g_dash.last_update_ms fresh — a gap over ~500 ms/2000 ms trips the UART‑bridge staleness handling on the side clusters. 0x3EE only needs to be sent when a warning state changes. Formulas mirror main/canbus.c exactly, inverted to compute the raw wire bytes from the display value you type.
