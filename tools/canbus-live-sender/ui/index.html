Auto-detects CANable-class adapters running candleLight/gs_usb firmware (the default for this hardware — same protocol CANgaroo already talks to). Needs the WinUSB driver bound via Zadig first, same one-time step CANgaroo required. COM ports are also listed in case the adapter is reflashed to slcan mode.

Bus settings (fixed, same for every frame)

Bitrate1,000,000 bps (1 Mbit/s)
ID typeStandard / 11‑bit (every ID below is < 0x800)
Frame typeData frame (not RTR)
DLC (data length)8 bytes, always
Byte orderBig‑endian — already baked into the bytes shown

What this covers

0x3E8 (10 ms)RPM, Boost/MAP, Coolant, IAT, Oil Temp
0x3E9 (10 ms)Ignition, Speed, Oil Pressure, Fuel Pressure
0x3EA (10 ms)Lambda
0x3EB (50 ms)Gear, Fuel Level
0x3EE (50 ms)6 warning flags → right‑screen overlay

Live send log

Send once transmits the frame's current bytes one time. Send continuously auto-repeats at that frame's documented period (10/50 ms) — matches what g_dash.last_update_ms needs to stay fresh; a gap over ~500 ms/2000 ms trips the UART‑bridge staleness handling on the side clusters. "Stop all continuous sends" and Disconnect both halt every running timer. Formulas mirror main/canbus.c exactly, inverted to compute the raw wire bytes from the display value you type.
